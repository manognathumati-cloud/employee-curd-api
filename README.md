# Employee CRUD API

## 📌 Project Description
This project is a REST API built using Spring Boot that performs CRUD operations on Employee data.

## 🛠 Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven

## 🚀 Features
- Create Employee
- Get Employee
- Update Employee
- Delete Employee
